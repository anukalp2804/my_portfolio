# Security policy

This is a static website: there is no server, database or login in this repository.

## Reporting a problem

If you find a security issue (for example a way to inject content into a page, or a leaked secret), please do **not** open a public issue.
Instead, use GitHub's **Security -> Report a vulnerability** option on the repository (if it is enabled),
or send a message through the contact form on the live website.

Please include what you found, where, and how to reproduce it. A reply can normally be expected within a few days.

## Supported version

Only the latest version of the `main` branch is maintained.

## Scope notes

- Social links, the public contact-form access key and links to public GitHub pull requests are **public by design**; they are not vulnerabilities.
- Reports about third-party services (Web3Forms, GoatCounter, hosting providers) should go to those services.
